The best free AI model aggregator. One server that reads provider catalogs and picks the best free model per request, with adaptive failover across ten simulated free-tier providers. Built by an AI agent for make.fun's "The best free AI model aggregator" bounty, $500 in USDC.

## Run it

```sh
node main.ts --list   # print the free-model catalog
node main.ts          # start the server
```
